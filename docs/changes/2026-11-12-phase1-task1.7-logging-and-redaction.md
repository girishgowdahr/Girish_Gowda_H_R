# Change Report: Phase 1, Task 1.7 — Structured Logging, Correlation IDs & Sensitive Data Redaction

**Date:** 2026-11-12  
**Task:** Phase 1, Task 1.7 — Structured logging with redaction + correlation IDs  
**Status:** Completed & Tested  

---

### Objective
Establish secure, auditable, and production-grade structured logging for the backend application. Implement a high-precedence correlation ID servlet filter (`CorrelationIdFilter`) to extract incoming `X-Correlation-ID` headers or generate UUID tracking tokens, populate SLF4J MDC (`correlationId`), and propagate the ID back in HTTP response headers. Configure Logback with a composite redaction converter (`RedactionPatternConverter`) to intercept and sanitize sensitive data (passwords, tokens, Bearer authorization credentials, session cookies, and email PII) across all application log statements.

---

### Protected Area Review Notice
- **Security & PII Protection:** `RedactionPatternConverter` actively intercepts all messages formatted by Logback appenders and masks credentials (`password=[REDACTED]`, `token=[REDACTED]`, `Authorization: Bearer [REDACTED]`, `__Host-session=[REDACTED]`, and `[REDACTED_EMAIL]`). This prevents secret leakage in container logs, centralized SIEMs, and developer consoles.
- **Traceability:** Correlation IDs ensure all log entries related to a single HTTP transaction or error incident are queryable without exposing private user data.

### Key Decisions (and why)
1. **Logback Composite Converter:** Extended `ch.qos.logback.core.pattern.CompositeConverter` to allow wrapping standard formatters `%redact(%msg)` natively within Logback without third-party wrapper dependencies.
2. **Order HIGHEST_PRECEDENCE:** Assigned `@Order(Ordered.HIGHEST_PRECEDENCE)` to `CorrelationIdFilter` so that correlation context is bound before Spring Security, exception handlers, and dispatchers execute.
3. **MDC Cleanup in Finally Block:** Enforced strict `MDC.remove(MDC_KEY)` in `finally` block to prevent correlation ID leakage across pooled servlet threads.
