### Key Decisions (and why)
1. **Accelerated Task Order (Option 1):** Fast-tracked Phase 1 Task 1.4 before Task 1.2 at owner's request to provide an immediate live visual preview in the browser.
2. **Accessible Base First (WCAG 2.2 AA):** Built skip link, high-contrast `:focus-visible` rings, semantic HTML5 landmarks, and `@media (prefers-reduced-motion: reduce)` directly into the CSS token layer.
3. **Strict Zero-Vulnerability Dependency Hygiene:** Updated `vitest` to version `5.1.0` ensuring `npm audit` reports 0 vulnerabilities.
4. **Synthetic Placeholder Guardrails:** All personal profile details are explicitly marked with `SYNTHETIC PLACEHOLDER` and link back to `docs/product/content-inventory.md` per Part A Rule 2.
5. **Tier C 2D Fallback on Lobby View:** Implemented the accessible 2D card representation for the operator identity so no WebGL or 3D engine is required to explore all views (conforming to Part A Rule 9).
