### Key Decisions (and why)
1. **Procedural Geometry over External Blobs:** Engineered the character using Three.js procedural geometries (capsules, cylinders, boxes, glowing emissive mesh materials) so that no heavy, copyrighted, or proprietary external Free Fire / Garena 3D binary assets are required. This strictly adheres to the Original Asset Policy and avoids slow network downloads.
2. **Accessible WebGL Detection & Graceful Fallback:** Implemented `checkWebGLSupport()` and safe try/catch wrapping around WebGLRenderer. If WebGL is unavailable or fails to initialize, the component automatically renders the clean SVG 2D tactical card with full text descriptions and keyboard-navigable controls.
3. **Respect for Reduced Motion:** Built frame delta clamping and pause triggers when `prefers-reduced-motion` is active.
4. **Interactive HUD Overlay:** Styled with authentic battle-royale HUD elements (Level 99 badge, rank badge, tactical skin selector, real-time pose switching) matching the Free Fire / modern battle royale lobby vibe.
