## 1. Summary of Changes
- Designed and implemented dedicated public read-only DTOs in `com.girish.portfolio.api.dto`:
  - `PublicProfileDto`: owner bio, location, email, verified social and resume URLs with zero private fields or database IDs.
  - `PublicSkillCategoryDto` & `PublicSkillItemDto`: grouped skills with proficiency level, years of experience, icons, and featured flags.
  - `PublicProjectDto`: projects with slug, description, category, parsed technology list, live/demo URLs, and featured flags.
  - `PublicExperienceDto`: career history with parsed highlights and technology tags.
  - `PublicEducationDto`: academic credentials.
  - `PublicCertificateDto`: verified certifications and licensures.
  - `PublicPortfolioSummaryDto`: composite public snapshot for high-performance single-roundtrip initial rendering.
- Implemented `com.girish.portfolio.application.PublicPortfolioService`:
  - Read-only transactional service fetching published data.
  - Implemented robust JSON array unmarshaling with support for double-encoded JSON strings.
- Implemented `com.girish.portfolio.api.PublicPortfolioController` exposing:
  - `GET /api/v1/public/portfolio` (full summary snapshot)
  - `GET /api/v1/public/portfolio/profile`
  - `GET /api/v1/public/portfolio/skills`
  - `GET /api/v1/public/portfolio/projects`
  - `GET /api/v1/public/portfolio/projects/{slug}`
  - `GET /api/v1/public/portfolio/experience`
  - `GET /api/v1/public/portfolio/education`
  - `GET /api/v1/public/portfolio/certificates`
  - `GET /api/v1/public/portfolio/resume` (downloadable markdown attachment)
  - High-performance caching with MD5 `ETag` calculation and `304 Not Modified` conditional response support, with `Cache-Control: public, max-age=60`.
- Implemented comprehensive integration test suite `PublicPortfolioControllerIntegrationTest` covering all endpoints, 200 responses, 404 RFC 9457 ProblemDetail on missing project slugs, conditional ETag validation, and resume download.
