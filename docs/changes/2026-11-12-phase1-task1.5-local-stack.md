# Change Report: Phase 1, Task 1.5 — Local Docker Compose Stack & Verification Scripts

**Date:** 2026-11-12  
**Task:** Phase 1, Task 1.5 — Local Docker Compose (Postgres, MinIO, MailHog) + setup/verify scripts  
**Status:** Completed & Tested  

---

### Objective
Provide containerized local infrastructure orchestration (`docker-compose.local.yml`) running PostgreSQL 16 (isolated schemas), MinIO (S3-compatible object storage with auto-bootstrapped public, private, and vault buckets), and MailHog (SMTP test sink with web inbox for security and MFA alert emails). Create cross-platform bootstrap and verification tooling (`setup.sh`/`setup.ps1`, `verify.sh`/`verify.ps1`) to ensure automated setup and end-to-end verification of the monorepo across all environments.

---

### Protected Area Review Notice
- **Infrastructure Configuration:** `docker-compose.local.yml` strictly uses environment variables with development fallback values (`${DB_USER:-girish}`, `${DB_PASSWORD:-girish_dev_password}`). Zero secrets committed.
- **MinIO Bucket Policies:** `minio-init` container automatically provisions 3 bucket tiers (`public`, `private`, `vault`) and enforces least-privilege policies: only `public` is accessible anonymously, while `private` and `vault` are private by default.

---

### Files Created
- `docker-compose.local.yml` — Container configuration for local infrastructure:
  - `postgres`: PostgreSQL 16 Alpine container with persistent named volume and `pg_isready` healthcheck.
  - `minio`: MinIO S3 object storage server with persistent named volume and `/minio/health/live` healthcheck.
  - `minio-init`: One-off initialization container using MinIO Client (`mc`) to create `girish-public`, `girish-private`, and `girish-vault` buckets with explicit download policies.
  - `mailhog`: Local SMTP container on port 1025 and Web UI on port 8025.
- `scripts/setup.sh` — Bash setup script checking prerequisites (Git, Node, npm, Java, Maven, Docker), generating `.env` from `.env.example`, installing frontend dependencies, and compiling backend.
- `scripts/setup.ps1` — PowerShell equivalent of `setup.sh` for Windows developers.
- `scripts/verify.sh` — Bash verification script executing TypeScript checks, Vitest suite, axe accessibility audit, Vite build, and Maven backend tests.
- `scripts/verify.ps1` — PowerShell equivalent of `verify.sh` for Windows developers.
- `docs/changes/2026-11-12-phase1-task1.5-local-stack.md` — This change report.

### Key Decisions (and why)
1. **Dual-Platform Scripting (Bash + PowerShell):** Provided parallel `.sh` and `.ps1` scripts so that both POSIX (macOS, Linux, WSL) and native Windows developer environments are fully supported with identical workflows.
2. **Automated Bucket Provisioning:** Added `minio-init` to `docker-compose.local.yml` so that bucket creation and access policies are completely automated upon startup rather than requiring manual admin console clicks.
3. **Graceful Degraded Mode:** `setup.sh` and `setup.ps1` test for Docker availability; if Docker is absent, the script informs the developer and proceeds with local lightweight testing without crashing.
