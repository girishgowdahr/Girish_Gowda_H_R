## 1. Summary of Changes
- Created canonical JSON Schema `backend/src/main/resources/schemas/module-manifest.schema.json` defining valid compile-time module manifest structure.
- Authored compile-time JSON manifests under `backend/src/main/resources/manifests/`:
  - `lobby.json`: 3D character staging environment, public route `/`, theme `theme-cyber-neon`.
  - `portfolio.json`: Public professional engineering portfolio, routes `/about`, `/skills`, `/projects`, `/education`, `/experience`.
  - `personal-fitness.json`: Tactical fitness tracker, private route `/app/fitness`.
  - `personal-study.json`: Learning and study matrix, private route `/app/study`.
  - `personal-journal.json`: Logbook and journal, private route `/app/journal`.
  - `vault.json`: Zero-knowledge encrypted vault, private route `/app/vault`.
- Implemented `com.girish.registry.domain.ModuleManifest` and `ModuleRoute` records.
- Implemented `com.girish.registry.application.ModuleManifestLoader` to scan and parse all classpath manifests dynamically.
- Implemented `com.girish.registry.application.ModuleRegistryReconciliationService` (`ApplicationRunner`) reconciling compile-time manifests with database table `core.module_state`, auto-registering new modules, reviving restored modules, and safely marking missing modules as `ORPHANED` while preserving owner overrides.
- Implemented `com.girish.registry.api.ModuleRegistryController` exposing `GET /api/v1/public/modules` with conditional `ETag` (`304 Not Modified`) and `Cache-Control: public, max-age=60`.
- Implemented `PublicModuleDto` with zero private fields and filtered out private/authenticated routes.
- Added test suite:
  - `ModuleManifestLoaderTest`: verifying discovery and field validity.
  - `ModuleRegistryReconciliationServiceTest`: verifying insertion, restoration, and orphan marking.
  - `ModuleRegistryControllerIntegrationTest`: verifying 200 OK, filtering of non-public modules, and 304 conditional request handling.
  - ArchUnit architecture fitness passing with zero package cycles.
