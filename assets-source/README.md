# 3D and 2D Asset Pipeline

This directory contains raw source assets, Blender project files, texture maps, licensing records, and optimization tooling for the GIRISH 3D avatar experience.

## Directory Structure
- `avatar/`: Base meshes, blend files, outfits, and licenses.
- `scenes/`: Background 3D scene environments and props.
- `catalogue/assets.json`: Machine-readable registry of verified assets, versions, and SHA-256 hashes.
- `pipeline/`: Scripts for `gltf-transform` Draco/Meshopt compression and WebP/AVIF fallback generation.

Refer to `NOT_ALLOWED.md` for copyright and original asset rules.
