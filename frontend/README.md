# Frontend (React 19 + TypeScript + Vite)

The frontend for GIRISH is a single-page application built with:
- **Framework:** React 19 + TypeScript + Vite
- **3D Engine:** Three.js + React Three Fiber + Drei (lazy-loaded, optional)
- **Styling & Tokens:** Accessible dark-theme design tokens
- **Testing:** Vitest, React Testing Library, Playwright, `@axe-core/playwright`

Application logic and components will be initialized in Phase 1 Task 1.4.
