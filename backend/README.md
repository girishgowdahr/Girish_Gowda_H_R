# Backend (Spring Boot Modular Monolith)

The backend for GIRISH is a Spring Boot application designed as a modular monolith:
- **Language / Runtime:** Java 21 LTS (or Java 25 LTS)
- **Framework:** Spring Boot 3.4.x / 4.0.x with Spring Security
- **Database:** PostgreSQL 16+ managed with Flyway migrations
- **Architecture Validation:** ArchUnit enforcing package-by-module boundaries
- **API Spec:** RESTful JSON endpoints with OpenAPI and RFC 9457 Problem Details

Application logic, configurations, and baseline migrations will be initialized in Phase 1 Task 1.2 and Task 1.3.
